How to use KeySprint

A physical-keyboard typing tutor with four levels and live feedback.

Getting started

  • Pick a level: 入门 Beginner (learn the keys) → 基础 Basic → 进阶 Advanced → 挑战 Challenge. Each level shows its WPM goal.
  • Click the input box, then type the passage with a physical keyboard. Correct characters turn blue, mistakes turn orange.

Useful actions

  • Want a new text? Try New passage.
  • Want to start over? Press Esc or hit Reset session.
  • Struggling with certain keys? Try Focus practice - it builds a short, randomized drill that features your weak keys more often.
  • In 挑战 Challenge, set a Target speed (WPM) and a Length (Short / Medium / Long). The text stays only as long as your target speed allows.

How results are measured

  • WPM = (correctly typed English characters / 5) / elapsed minutes. Spaces and punctuation count; wrong characters do not.
  • Mistakes = every wrong keystroke, counted in real time, even after you correct it. Corrections = backspace/delete presses.
  • Accuracy = correct keystrokes / (correct keystrokes + mistakes).
  • Session score = 70% accuracy + 30% speed (speed capped at 60 WPM), scaled to 0-100.
  • Weak keys = the letters you miss most, ranked by error rate then error count. KeySprint remembers them in your browser (localStorage) to power Focus practice; clear your site data to reset this memory.
